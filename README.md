# DOT EDITOR — ドット絵エディタ

ブラウザだけで動く、単一HTMLファイルのドット絵（ピクセルアート）エディタです。
インストール・ビルド不要。`index.html` を開くだけで使えます。

**▶ オンラインで使う: https://fumiakim.github.io/pixel-editor/**

![256色パレット / 1〜4コマ / PNG透過書き出し](https://img.shields.io/badge/-256色%20%7C%201〜4コマ%20%7C%20PNG透過-59c2ff)

## 特徴

- **任意のキャンバスサイズ** — 1×1 〜 512×512px を自由に指定。サイズ変更しても絵は左上基準で保持されます。
- **256色インデックスカラー** — パレットの色を変更すると、全コマの該当ピクセルに一括で反映されます。
- **アニメーション 1〜4コマ** — 追加・複製・削除、FPS可変のループ再生。
  オニオンスキンは前のコマを**青**、次のコマを**赤**に着色して薄く重ねるので、現在のコマと一目で見分けられます。
- **画像の読み込み** — PNG/JPEG などを読み込んでドット絵化。画像に合わせた256色パレットの自動生成（中央値分割法）と、現在のパレットのまま減色のどちらかを選べます。元画像の透明部分は透明のまま取り込まれます。
- **PNG書き出し（透過対応）** — 未描画部分はアルファ0で出力。1〜16倍の整数倍拡大（にじみなし）。
  - 現在のコマ / スプライトシート（横並び）/ 全コマを個別に
- **作業内容の自動保存** — localStorage に自動保存。上部の「保存」「開く」で `.json` プロジェクトの保存・読込にも対応。

## ツール

ペン / 消しゴム / 塗りつぶし / スポイト / 直線 / 四角 / 円 / 全体移動、
ブラシ太さ1〜4、Undo・Redo（60段）、グリッド表示、左右反転・上下反転、ズーム。

### ショートカット

| キー | 動作 |
|---|---|
| `B` `E` `G` `I` | ペン / 消しゴム / 塗りつぶし / スポイト |
| `L` `R` `O` `M` | 直線 / 四角 / 円 / 移動 |
| `⌘Z` / `⇧⌘Z` | 元に戻す / やり直し |
| `[` `]` | 前のコマ / 次のコマ |
| `Space` | プレビュー再生・停止 |
| 右ドラッグ | 消しゴム |
| `Alt` + クリック | スポイト |

## 使い方

上のリンクからそのまま使えます。ローカルで使う場合は、このリポジトリの `index.html`
をダウンロードしてブラウザで開いてください（サーバー不要）。

## 技術メモ

- 依存ライブラリなし。HTML + CSS + Canvas 2D のみ、単一ファイル。
- 各コマは `Int16Array(w × h)` にパレット索引を保持し、`-1` を透明として扱うインデックスカラー方式。
- 表示は等倍の Canvas を `image-rendering: pixelated` で拡大。書き出しも同じ画素値をそのまま整数倍するため、色がにじみません。

## 動作環境

Chrome / Safari / Edge / Firefox の最新版（デスクトップ推奨）。
