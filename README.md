# DOT EDITOR — ドット絵エディタ

ブラウザだけで動く、単一HTMLファイルのドット絵（ピクセルアート）エディタです。
インストール・ビルド不要。`index.html` を開くだけで使えます。

**▶ オンラインで使う: https://pixel-editor-peach.vercel.app/**
（ギャラリーなしの静止版: https://fumiakim.github.io/pixel-editor/ ）

![256色パレット / 1〜10コマ / PNG透過書き出し](https://img.shields.io/badge/-256色%20%7C%201〜10コマ%20%7C%20PNG透過-59c2ff)

## 特徴

- **ギャラリー「みんなの作品」** — 描いた絵を投稿して、合言葉を知っている人どうしで共有できます。
  一覧のサムネイルはその場でアニメーションし、クリックすると自分のキャンバスに読み込めます（`⌘Z` で元に戻せます）。
  投稿できるのは 128×128px まで、最新60件を保持します。**この機能は Vercel 版でだけ使えます。**
- **サンプル（お手本）** — ギャラリーの「サンプル」タブから、キャラクター22種を読み込めます
  （ねこ・スライム・ロボット・ことり・おばけ・UFO・うさぎ・ペンギン・カエル・さかな・
  きょうりゅう・ちょうちょ・くるま・ロケット・ドラゴン・ナイト・にんじゃ・ガイコツ・
  オオカミ・サメ・まほうつかい・ジェットき）。どれも 16×16ドット・2コマの
  アニメーション付きなので、動きの付け方の参考にもなります。ギャラリーではその場で動いて見えます。
  読み込んだあとは自由に描きかえてOK。`⌘Z` で元の絵に戻せます。

- **任意のキャンバスサイズ** — 1×1 〜 4096×4096px を自由に指定。サイズ変更しても絵は左上基準で保持されます
  （1024×1024を超えると動作が重くなるため確認が出ます）。
- **256色インデックスカラー** — パレットの色を変更すると、全コマの該当ピクセルに一括で反映されます。
- **アニメーション 1〜10コマ** — 追加・複製・削除、FPS可変のループ再生。
  オニオンスキンは前のコマを**青**、次のコマを**赤**に着色して薄く重ねるので、現在のコマと一目で見分けられます。
- **画像の読み込み** — PNG/JPEG などを**元画像のピクセル数そのまま（原寸）**でドット絵化。画像に合わせた256色パレットの自動生成（中央値分割法）と、現在のパレットのまま減色のどちらかを選べます。元画像の透明部分は透明のまま取り込まれます。
  **APNG は全コマを読み込んで**コマ1〜10に展開するので、書き出したアニメーションを読み直して続きから編集できます（11コマ以上のものは先頭10コマ）。
- **PNG書き出し（透過対応）** — 未描画部分はアルファ0で出力。1〜16倍の整数倍拡大（にじみなし）。
  - 現在のコマ / スプライトシート（横並び）/ 全コマを個別に
- **APNG（動くPNG）書き出し** — アニメーションを1枚のファイルに。透過を保ったまま無限ループし、
  拡張子は `.png` のまま主要ブラウザでそのまま再生できます。表示速度はプレビューのFPS設定に連動。
  外部ライブラリを使わず、`CompressionStream` を用いた自前のAPNGエンコーダで生成しています。
- **作業内容の自動保存** — localStorage に自動保存。上部の「保存」「開く」で `.json` プロジェクトの保存・読込にも対応。

## ツール

ペン / 消しゴム / 塗りつぶし / スポイト / 直線 / 四角 / 円 / 全体移動、
ブラシ太さ1〜4、Undo・Redo（60段）、グリッド表示、左右反転・上下反転、ズーム。

### ショートカット

| キー | 動作 |
|---|---|
| `B` `E` `G` `I` | ペン / 消しゴム / 塗りつぶし / スポイト |
| `L` `R` `O` `M` | 直線 / 四角 / 円 / 移動 |
| `⌘Z` / `⇧⌘Z` | 元に戻す / やり直し |
| `[` `]` | 前のコマ / 次のコマ |
| `Space` | プレビュー再生・停止 |
| 右ドラッグ | 消しゴム |
| `Alt` + クリック | スポイト |

## 使い方

上のリンクからそのまま使えます。ローカルで使う場合は、このリポジトリの `index.html`
をダウンロードしてブラウザで開いてください（サーバー不要）。

## 技術メモ

- 依存ライブラリなし。HTML + CSS + Canvas 2D のみ、単一ファイル。
- 各コマは `Int16Array(w × h)` にパレット索引を保持し、`-1` を透明として扱うインデックスカラー方式。
- 表示は等倍の Canvas を `image-rendering: pixelated` で拡大。書き出しも同じ画素値をそのまま整数倍するため、色がにじみません。
- APNG は仕様（acTL / fcTL / fdAT チャンク）に沿って自前で組み立てています。圧縮は `CompressionStream('deflate')`
  を使い、非対応環境では非圧縮の stored ブロックによる zlib ストリームにフォールバックします。
- APNG の読み込みは、各コマを「独立した1枚のPNG」に組み直してブラウザ本体にデコードさせる方式です。
  これにより PNG のフィルタ・ビット深度・カラータイプ（パレット画像を含む）の解読を自前で持たずに済みます。
  そのうえで `fcTL` の配置オフセットと `dispose_op` / `blend_op` に従って合成し、各コマの完成画を作ります。

## 動作環境

Chrome / Safari / Edge / Firefox の最新版（デスクトップ推奨）。

## ギャラリーのしくみ（Vercel 版）

エディタ本体は単一HTMLのままで、ギャラリーのぶんだけサーバー機能を足しています。

```
index.html          エディタ本体（ビルド不要・そのまま配信）
api/login.js        合言葉の照合とセッション発行
api/gallery.js      投稿の一覧 / 追加 / 削除
api/_lib.js         署名付きCookieと Vercel Blob の読み書き
```

- **保存先** … Vercel Blob の private ストア。Blob の URL を直接叩いても `403` で、
  中身はサーバー経由でしか読めません。1作品=1ファイルなので、同時に投稿しても取りこぼしません。
- **合言葉** … サーバー側（環境変数 `APP_PASSWORD`）で照合し、HMAC-SHA256 で署名した
  HttpOnly / Secure な Cookie を発行します。閲覧・投稿・削除のすべてでこの Cookie を検証します。
- **投稿データ** … ブラウザ側で gzip して base64 で送ります。128×128・4コマの複雑な絵でも約8KBです。

### セットアップ

```bash
npx vercel link
npx vercel blob create-store dot-gallery --access private --yes
npx vercel env add APP_PASSWORD production        # 合言葉
npx vercel env add APP_AUTH_SECRET production     # openssl rand -hex 32 の出力
npx vercel --prod
```

### 注意点

- 合言葉は**共有の合言葉**です。知っている人は誰でも閲覧・投稿・削除ができます。
  誰が消したかは記録していないので、大切な絵は `.json` でも保存しておいてください。
- 数字6桁は総当たりに強くありません。失敗のたびに待ち時間を入れ、10回で10分ロックしていますが、
  厳密な保護が必要な用途には長い合言葉に変更してください（環境変数を変えるだけです）。
- エディタ画面そのものは誰でも開けます。守っているのは**投稿された作品のデータ**です。
